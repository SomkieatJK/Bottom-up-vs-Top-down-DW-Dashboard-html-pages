เส้นทางการสร้าง

Bottom-upSource→Staging→Data Mart (Star)→Conformed Dim / Bus

สร้าง Data Mart ทีละกระบวนการธุรกิจ แล้วเชื่อมกันด้วย conformed dimensions จนได้มุมมององค์กร

Top-downSource→Staging→Enterprise DW (3NF)→Dependent Data Mart

สร้างคลังข้อมูลองค์กรแบบ normalized ให้ครบก่อน แล้วค่อยแตก Data Mart ออกไปให้แต่ละแผนก

เหมาะกับ Bottom-up

  • ต้องเห็นผลเร็ว งบและทีมจำกัด
  • ผู้ใช้ธุรกิจต้องการ query เองได้ง่าย
  • วางแผนเพิ่ม Data Mart ทีละเรื่อง

ข้อควรระวัง: ถ้าไม่คุม conformed dimensions จะเกิด data mart แยกเกาะ

เหมาะกับ Top-down

  • องค์กรใหญ่ ต้องการข้อมูลกลางที่เป็นหนึ่งเดียว
  • มีทีมออกแบบข้อมูลและงบระยะยาว
  • มีหลายแผนกใช้ข้อมูลร่วมกันและต้องตรงกัน

ข้อควรระวัง: ใช้เวลานานกว่าจะเห็นผล และมีความเสี่ยงโครงการบานปลาย
